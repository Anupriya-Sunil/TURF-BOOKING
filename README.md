# ⚽ Turf Booking System

## 📌 Project Overview

The **Turf Booking System** is a web-based application developed using Python and Django REST Framework. It provides an easy way for users to view turf facilities, register accounts, log in securely, and book turf grounds for their preferred dates and time slots.

The system includes turf management, user authentication, booking management, and booking cancellation features. It also prevents overlapping bookings for the same turf.

## 🚀 Features

* User Registration and Login
* Unique Sequential User Codes (TOKEN001, TOKEN002, etc.)
* Token-Based Authentication
* Add, View, Update and Delete Turf Details
* Create Turf Bookings
* View Personal Booking Details
* Cancel Bookings
* Prevent Overlapping Bookings
* User-Specific Booking Management
